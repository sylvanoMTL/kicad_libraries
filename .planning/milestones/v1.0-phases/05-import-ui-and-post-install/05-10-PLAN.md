| Boundary | Description |
|----------|-------------|

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-05-31 | Tampering | a carried Overwrite applied to another library's item | medium | mitigate | Choices are kept by Conflict.key, which includes the library (D-14a). test_conflict_choice_carried_by_key |
| T-05-32 | Denial of Service | overlapping build_plan calls racing the kicad-cli cache | low | mitigate | One serial build queue, at most one build worker. test_builds_never_overlap |
| T-05-SC | Tampering | npm/pip/cargo installs | high | accept | No package is installed by this plan |
