## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user click -> git writes | Every commit and switch must follow an explicit click (PROJECT.md Safety) |
| GUI thread <-> worker threads | Workers must not read state the GUI can change |
| app shutdown -> running git job | Closing must not abandon a commit halfway |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
