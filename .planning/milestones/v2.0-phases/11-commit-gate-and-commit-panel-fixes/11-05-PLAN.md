<objective>
Extend the commit gate to the symbols a commit can break without touching their library: those that link a committed footprint or 3D model (D-04). Only failures this commit introduces block; failures that were already there become the D-02 amber note.

Purpose: GIT-06 ("While any part being committed fails the atomic check, the commit panel refuses"). A shared `Atomic_Footprints` footprint overwrite can break every part that links it; this is the case the user called out in D-04.
Output: `run_gate` handles committed footprints and models with a HEAD-view comparison, and the tests.
</objective>
