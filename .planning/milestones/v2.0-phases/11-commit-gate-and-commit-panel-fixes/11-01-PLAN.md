<objective>
Let git identity come from the environment, as REV-11 (Phase 6 IN-03) asks, without reopening the door to environment variables that redirect git to another repository.

Purpose: success criterion 4 of Phase 11, "A user whose git identity comes from GIT_AUTHOR_* / GIT_COMMITTER_* variables can commit from the panel". Today `_env` strips every `GIT_*` variable, and `identity_known` checks only the committer ident, so an env-only identity is either thrown away or reported as ready and then fails (RESEARCH Pitfall 2, experiment E3).
Output: `gitops._env` allow-list, the `stdin_data` rename, a two-ident `identity_known`, and their tests. The panel-facing identity message is changed in plan 11-07 (it lives in `commit_step.py`).
</objective>
