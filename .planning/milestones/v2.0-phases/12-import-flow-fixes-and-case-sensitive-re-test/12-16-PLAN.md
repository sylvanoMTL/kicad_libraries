<objective>
Close the Qt-free half of UAT gap G-12-21: "While the app loads the libraries at startup, the loading dialog offers a way to skip the library being scanned (e.g. the whole Wurth Elektronik library) so startup is faster, without breaking the scan result." ## Choices made here (planner's discretion)

- **Hook shape.** Two keyword-only plain callables on `scan_all`, matching the existing `progress` style: `checking: Callable[[str | None], None] | None` and `skip: Callable[[str], bool] | None`. The worker thread calls them; plan 12-17's ScanWorker turns `checking` into a Qt signal and answers `skip` from a lock-guarded set. Nothing Qt crosses into the scanner.
- **What a skip removes.** Only the 3D model path lines of that source (codes scan.unreadable, scan.model_var, scan.model_missing, scan.model_absolute for files of that source), including the ones found before the click, so the result says plainly "not checked" for the whole source. The atomic check, which also judges model files of Atomic_ parts, is a different rule and still runs.
- **The skip line.** `Issue(Severity.INFO, "scan.models_skipped", text)` built by a public helper `models_skipped_issue(sources, rechecked=())` in library_scanner. Without rechecked libraries the text is exactly: "3D model paths of {names} were not checked: skipped while the libraries loaded. Rescan checks them." where names joins the sorted sources with " and ". With rechecked libraries: "3D model paths of {names} were not checked, except {libs} (rescanned since): skipped while the libraries loaded. Rescan checks them." where libs joins the sorted nicknames with ", ". INFO, not WARNING: a skip is the owner's choice, not a problem in a library; plan 12-17 stops "No warnings." from being claimed after a skip. It sits right after the 3D path lines, and `_rank` ranks it 0 with them so a one-library rescan keeps that place. It is not a global code, so a rescan keeps it (and updates it, below).
- **What a skip left unchecked, per library (checker revision).** The owner's skip unit stays the source (the button, `skipped_sources`, the line's names); the result also records per library what is still unchecked, so a one-library rescan can never leave the line saying a checked library was not checked. `ScanResult.models_unchecked: list[str]` holds the sorted repo-relative paths of the rel_path of every footprint library of each skipped source (`FootprintLibrary.rel_path` whose `source` was skipped), plus the rel path of any footprint file of that source that lies in no footprint library (no such file exists today; it stays unchecked until a full Rescan). For a result made by `scan_all` or `rescan_library`, `skipped_sources` always equals the sorted sources that still have an entry in `models_unchecked`. A one-library rescan of footprint library L whose rel_path is in `models_unchecked` removes it (its 3D model paths were just checked), drops every source left with no entry from `skipped_sources`, and replaces the old skip line with `models_skipped_issue(skipped_sources, models_rechecked(result))`, or removes it when no source is left. Public helper `models_rechecked(result) -> list[str]` (docstring): the sorted nicknames of the footprint libraries of a skipped source whose rel_path is not in `models_unchecked`, counted only for skipped sources that have at least one entry in `models_unchecked` (a hand-built result with skipped sources and an empty record, as in plan 12-17's tests, reads as wholly unchecked and keeps the plain line).
- **Saved scan format.** `FORMAT = 2`; `encode_result` adds "skipped_sources" and "models_unchecked", and `decode_result` requires each as a list of text. A format 1 file reads as "made by a different version" and runs one full scan, which the code change forces anyway.
- **Reuse note with a skip.** "Showing the saved scan from {when}: no library file changed since then. The 3D model paths of {names} were skipped in that scan; use Rescan for a full scan." When `models_rechecked(result)` is not empty: "... The 3D model paths of {names} were skipped in that scan, except {libs} (rescanned since); use Rescan for a full scan." Without a skip the note is unchanged.
- **Narrowed signature.** `_scan_code_files(package: Path) -> list[str]` walks the package-internal relative imports (ast, anywhere in each module, function-level imports included) from `library_scanner.py` and `scan_cache.py`. A probe on 2026-11-04 gives 15 files: `__init__.py`, `atomic_check.py`, `changes.py`, `fsutil.py`, `gitops.py`, `importer/__init__.py`, `importer/fieldrules.py`, `importer/package.py`, `kicad_files.py`, `kicad_process.py`, `library_scanner.py`, `manufacturers.py`, `models.py`, `scan_cache.py`, `sexpr.py`. Resolution rules: `from .x import y` is `x.py` or `x/__init__.py`, and when x is a package each imported name that is a module of it (`y.py` or `y/__init__.py`) counts too; `from . import a, b` resolves each name as a module of the importing module's package, never the package folder plus ".py" (the repo root holds `kicad_lib_manager.py`, which the probe wrongly picked up at first); every `__init__.py` on the dotted path counts; a level above 1 climbs one folder per extra dot; anything outside the package is ignored. The package holds no data files the scan reads (only `.py`; checked 2026-11-04).
- **Progress bands.** From the measured times (listing 0.25 s, symbol links 6 s, 3D check 63 s): footprint libraries 0-1, symbol libraries 1-10, 3D check 10-92, atomic check at 92, change check at 96, Done at 100. Each phase's own (i, n) maps into its band; the callback always receives total 100.
