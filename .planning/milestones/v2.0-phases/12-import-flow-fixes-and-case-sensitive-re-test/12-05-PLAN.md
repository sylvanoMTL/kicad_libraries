<objective>
Fix 05-REVIEW WR-03 (REV-03) and the Change.../open half of WR-05 (REV-04): a one-off conflict build can no longer overlap Install, and the GUI thread no longer waits for a build before it changes or opens a package. A visible Finishing state takes the wait's place and runs the requested action by itself. Plan 12-07 extends the same state to closing.

Purpose: ROADMAP success criterion 2.
Output: Finishing state (strip, Cancel, 10 s note, pending action), Change/open deferral, bounded `_reap`, Install gating and build holding around installs, dialog tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker threads -> GUI thread | build, one-off and open results arrive as queued signals |
| user leave-requests -> running workers | Change..., open and Cancel arrive while kicad-cli may run for up to 60 s |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-12-10 | Denial of service | GUI thread during Change/open | high | mitigate | No unbounded join on the GUI thread; the action is deferred to `_reap`/`_try_finish`; `test_change_never_waits_unbounded` records every `TaskWorker.wait` call and requires a timeout of at most 2000 ms |
| T-12-11 | Tampering | package closed under a running build | high | mitigate | `_do_change`/`_do_open` run only when `_busy_builds()` is empty; `test_change_waits_for_build_without_blocking` asserts the package closes after the build ended |
| T-12-12 | Tampering | one-off build reading the library while Install writes it | high | mitigate | `_updating()` counts the one-off (Install disabled) and `_pump_builds` holds every job while installing (`test_install_disabled_while_oneoff_runs`, `test_oneoff_held_during_install_runs_after_failure`) |
| T-12-13 | Denial of service | worker object lifetime | medium | mitigate | Finished workers stay referenced in `_workers` and are never deleteLater'd; `_reap` keeps a bounded join so a QThread is never destroyed while running |
| T-12-SC | Tampering | npm/pip/cargo installs | low | accept | No package is installed or upgraded by this plan |
</threat_model>
