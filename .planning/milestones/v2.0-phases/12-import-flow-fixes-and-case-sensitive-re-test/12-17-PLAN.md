## Choices made here (planner's discretion)

- **Dialog.** `ScanProgressDialog(QDialog)` in `kicad_lib_manager/widgets/scan_progress.py`: title "Loading Libraries", window-modal over the main window as today, a plain-text label, a QProgressBar 0-100, and a bottom row with a stretch and `skip_button`. `skip_requested = Signal(str)`. `set_progress(text, value)` sets the label and the bar (capped at 99 by the caller as today). `set_skippable(source)`: with a source the button reads "Skip {source}", is enabled, and its tooltip is "Stop checking the 3D model paths of {source}. Its libraries are still listed, and Rescan checks them again."; with None it reads "Skip", is disabled, and its tooltip is "Skip is offered while the 3D model paths of a library source are checked.". A click emits the source once, then the button reads "Skipping {source}..." and is disabled, until the next `set_skippable` call (the scan's next report: the next source, or None at the end of the check) replaces it; the button never keeps claiming a skip the scan did not make. `reject()` does nothing until `finish()` was called (so Escape and the title-bar X are inert, because QDialog's close event goes through reject); `finish()` marks the dialog finished and closes it. No auto-default button.
- **Worker.** `ScanWorker.checking = Signal(object)` (a source name or None). A `threading.Lock` guards a set of requested sources: `request_skip(source)` (GUI thread) adds, a private `_skip_requested(source)` (worker thread) reads. `run()` passes `skip=self._skip_requested, checking=self.checking.emit` to `scan_all`. The saved-scan path is unchanged: the result carries `skipped_sources`, so it is saved with them (plan 12-16).
- **Log (checker revision: the log, the button and the scan result agree).** `_on_skip_requested(source)` only forwards the request and writes no log line: a click can reach the GUI thread after the worker asked about that source's last file, and such a request is recorded but never consulted (plan 12-16 asks `skip` per file and adds a source to `skipped_sources` only when the answer was True). The one skip line is therefore the scan result's own issue (plan 12-16's `models_skipped_issue`, built from `ScanResult.skipped_sources`), logged with the other issues at the end, so the log names a source only when its check really was skipped. When no issue warns: "No warnings." when `result.skipped_sources` is empty, else "No warnings in the checks that ran." (success colour). Mechanism chosen: the second route of the checker's hint (wording derived from the finished result), the smallest one, since 12-16 already builds that line.
- **Tests' fake scan.** Both `make_window` fixtures accept the hooks by name, `fake_scan(root, progress=None, kicad_fp_dir=None, *, skip=None, checking=None)`, and store them on `make.hooks` (the last call's `(skip, checking)`) before calling a callable item, so a gated item can drive the dialog. A wrong keyword still fails loudly.
