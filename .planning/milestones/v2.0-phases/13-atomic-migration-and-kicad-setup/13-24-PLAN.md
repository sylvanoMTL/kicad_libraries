<objective>
Close gap G-13-1-b: on the owner's checkout the Loading Libraries window keeps **Skip** greyed for about 9 s (listing plus a 6 s symbol parse over 412 files, one of them 12.9 MB) before the long WurthElektronik 3D model path check (about 100 s) starts and Skip appears. The owner reported "the skip button is grayed out ... for the symbol scanning. This should not be grayed out." Diagnosis: `.planning/debug/skip-greyed-symbol-scan.md`. Skip is enabled only by `checking(source)`, which `scan_all` passes solely to `_check_model_files`; `find_symbol_libs` gets only `progress`.

Owner decision (2026-11-12, given to this planning round): the owner wants to skip from the start of the scan, and the only safe form is an **early "Skip <source>" that pre-registers that source's 3D-model-check skip while the symbol parse still completes**. Skipping the symbol parse itself is ruled out: `_merge_table` deletes managed entries that are not scanned and `_sync_footprint_selection` would uncheck that source's footprints, which breaks the contract "a skip never drops a library or a footprint link". The backend already honours an early request: `ScanWorker._skip_sources` is a sticky per-source set that `_check_model_files` asks per file. Only the reporting and the dialog change.

This **amends the 2026-11-04 owner decision recorded for plan 12-17** (`12-UAT.md` "Owner Decisions", G-12-21: "skipping only that source's 3D model path check" with Skip offered only during that check). What a skip does is unchanged (the unit is still the source, and only its 3D model path check is skipped); what changes is *when* it is offered. Task 2 records the amendment.

Purpose: the owner can cut WurthElektronik's long 3D check as soon as the window opens, without any risk to the library list or Generate Tables.
Output: `find_symbol_libs(..., checking=...)`, a dialog that remembers requested skips, new tooltip texts, updated docs, and regression tests at scanner and window level.
</objective>
