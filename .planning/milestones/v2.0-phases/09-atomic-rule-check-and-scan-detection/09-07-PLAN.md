<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user input -> FixSpec | Typed Datasheet and Description text and the picked model path become file content |
| dialog -> file writes | The dialog is the only place fixes are written from |
| scan text -> dialog widgets | Symbol names and reasons from vendor files are shown in labels and rows |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-18 | Tampering | apply without preview | high | mitigate | Only the preview page's Apply button calls apply_preview, on the FixPreview just shown; tested by recording apply_preview calls |
| T-09-19 | Tampering | KiCad overwriting fixes (D-16) | medium | mitigate | The running warning is shown on the preview page; apply_preview's SHA-256 check refuses a file KiCad saved after the preview; tested |
| T-09-20 | Spoofing | rich text in rows and labels | low | mitigate | Rows are plain QTreeWidgetItem text; the summary, reason and running labels use `Qt.TextFormat.PlainText`, so vendor text is never interpreted as markup |
| T-09-21 | Tampering | typed Datasheet value | low | mitigate | Validated by `datasheet_problem` (D-17) before it can become a fix; never fetched or opened |
| T-09-SC | Tampering | npm/pip/cargo installs | low | accept | This plan installs no packages (RESEARCH Package Legitimacy Audit: none) |
</threat_model>
