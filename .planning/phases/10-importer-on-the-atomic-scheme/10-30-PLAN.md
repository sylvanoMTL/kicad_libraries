<objective>
Close UAT gap G-10-11 (severity minor). When ATXK-H14 is opened, nothing places the part, so the library field stays empty (owner decision of UAT test 14: it asks). The strip then shows only "Pick or type a library name". The other four reasons appear only after a library is typed. The cause is in build_plan: it returns at the name check, before the atomic gate runs (D-21). blocking_reasons then drops that one ERROR as already explained and adds the form's library line. This affects every refused name, not only the empty one.

The fix follows the owner decisions of 2026-10-29. In the strip, "Pick or type a library name" comes first, then the plan reasons. A refused library name must never produce file operations. install.official_missing stays as it is. build_plan holds the name refusal aside, plans the part as for a new library it never reads, runs the gate, and returns a blocked plan with no operations that carries every library-independent reason plus the refusal. blocking_reasons moves the library reason to the front.

Purpose: the owner sees everything that blocks Install at once and can fix the fields in any order (LIB-07, D-25). The name rule still refuses the same names (LIB-05, D-08, D-13).
Output: the deferred refusal in `planner.py`, the library-first order in `form.py`, an ATXK-H14 planner/form test and a dialog test, the refused-name neighbour tests, the 10 single-ERROR tests updated, one tests/README.md skip row, check 8 of 10-VERIFICATION.md, and the combined gate for both gap plans.
