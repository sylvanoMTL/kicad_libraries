## Flagged Assumptions

- **Allowed set = snapshot union installed (RESEARCH A9).** A KiCad 9 install lacks Converter_DCDC_Isolated; the snapshot keeps it allowed.
- **Case variants are refused until corrected (D-11).** The verdict carries the corrected name; the dialog applies it when editing finishes (plan 10-15), and build_plan refuses the uncorrected spelling, so it never installs under a name the user did not see.
- **Hand-made Atomic_ libraries that are not Atomic_<stem> are refused (RESEARCH A5).** None exist today.
- **Edge (LIB-05 empty):** an empty or blank name is refused with "Pick or type a library name".
- **Edge (LIB-05 encoding):** acceptance needs the exact official spelling; casefold is used only to find the correction, and the snapshot is unique under casefold.
