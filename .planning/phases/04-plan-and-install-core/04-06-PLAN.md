| Boundary | Description |
|----------|-------------|
| caller-edited library name -> filesystem paths | The library name becomes `<name>.kicad_sym` and `<name>.pretty` inside Custom/ |
| vendor symbol format -> target library | A newer format inside an older library makes KiCad fail or lose data |
