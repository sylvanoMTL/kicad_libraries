   - `set_property_edit(prop: PropertyRef, value: str) -> Edit` replacing only the value token.
   - `next_property_id(symbol_node: Node) -> int | None`: max of the `(id N)` children of direct `property` children plus one, or None when no property carries an id.
   - `new_property_text(text: str, template: PropertyRef, name: str, value: str, next_id: int | None) -> str`: the template node's text slice re-parsed, with name token, value token and (only when the template has an `(id N)` child and next_id is not None) the id atom replaced, via one `apply_edits` call.
   - `property_insert_edit(text: str, symbol_node: Node, block: str, eol: str) -> Edit`: zero-width insert after the last direct `property` child, as `eol + indent + normalize_eol(block, eol)` with the indent of that property's line.
