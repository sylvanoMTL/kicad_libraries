<objective>
Close review warnings WR-03 and WR-05 in the planner/candidate layer, before the Phase 5 form and caller exist.

WR-03 is the Phase 3 WR-05 defect, half fixed. Package-level Issues (depth limit, unreadable members, skipped links, ignored members) live on `Package.issues`, and `ImportCandidate.issues` does not carry them. `build_plan(package_issues=())` only works when every caller remembers to forward them, and no e2e test proves the path. This plan makes the data path structural: `detect_candidate` folds them into the candidate, de-duplicated, as the review proposes.

WR-05: `InstallOptions` overrides are tested with `is not None`. The empty string `""` that a Qt line edit returns for an untouched field therefore blanks the vendor MPN, Value and Datasheet, adds an empty description property, and makes the model file name silently fall back. This plan normalises the fields in one place, `InstallOptions.__post_init__`.

Per the user decision recorded on 2026-10-20 ("Blank = not set; defer clear"), an empty field means "not set, keep the vendor value", and no clear sentinel is added. PREV-04 lets the user edit these five fields in the preview, and an edit can mean emptying one, so PREV-04 can ask for a clear. That explicit "clear this field" outcome is deferred to Phase 5 as a preview decision (see "Deferred to Phase 5" below).

Purpose: INTK-08 needs warnings to reach the preview and the log. The package-level reason (for example a model skipped in a too-deep folder) must travel with the candidate to `plan.issues` and `InstallResult.issues`. INST-04 and D-11 need the model named `<MPN>.<ext>` and Manufacturer/MPN filled from the vendor when the caller typed nothing.
Output: structural package-Issue path, blank-means-unset options, and their unit and e2e tests.

Gap closure scope: plans 04-01 to 04-10 and their SUMMARY files stay untouched. `build_plan` keeps its `package_issues` keyword (non-breaking): it adds extra Issues, and duplicates appear once. Plan 04-13 records the review dispositions after this plan and 04-11 have landed.
