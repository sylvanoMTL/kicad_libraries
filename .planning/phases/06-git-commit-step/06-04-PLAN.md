<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| package metadata -> commit message | Vendor, symbol and package file names come from an untrusted download |
| install result -> commit plan | Paths come from the plan and must stay inside Custom before any of them reaches git |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-13 | Tampering | committing a path outside Custom | high | mitigate | build_commit_plan resolves each path and refuses one not under custom_dir (commit.outside_custom), which makes the step unavailable. test_build_refuses_outside_custom |
| T-06-14 | Tampering | trailer or line injection through a package file name | medium | mitigate | sanitize_line on every interpolated value (controls to spaces, collapse, strip). test_default_message_sanitises_controls |
| T-06-18 | Information Disclosure | local paths or the user name published in commit messages (pushed later by hand) | low | mitigate | Import-Package is the base name only; no path is formatted into the message. test_default_message_has_no_local_paths |
| T-06-SC | Tampering | npm/pip/cargo installs | high | accept | No package is installed by this plan |
</threat_model>
