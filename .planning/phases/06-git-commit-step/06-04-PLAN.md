Make the commit itself exact and safe in every case the tracer did not cover. The commit plan and the messages follow D-18 to D-20 to the letter (GIT-04), with untrusted names sanitised and no local paths. run_commit refuses before writing anything when a file changed after the install (D-11), when either repo changed since the probe, or when a path is ignored. The commit contains exactly the listed files with every bystander change left alone (GIT-02, D-10, D-17), including awkward file names. The parent message lists every commit the bump covers (D-13), and the D-09 diff view has its content builder.
