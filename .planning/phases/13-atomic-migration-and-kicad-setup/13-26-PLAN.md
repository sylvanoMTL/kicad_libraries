<objective>
Close the visibility half of gap G-13-1-f. In the owner's live run the migration put ICM-42688-P into `Atomic_Timer` and nothing said so: the gate's only library line is "Choose a library for X" when the target is empty (`gate.py:184`), the window shows a suggestion exactly like a choice (the reason and runner-up only in a combo tooltip), and the dropdown lists only libraries other parts already target, so `Atomic_Sensor_Motion` was not even offered (`.planning/debug/imu-suggested-atomic-timer.md`, 18:30 evidence). Once the atomic-rule lines were fixed, Run would have accepted the wrong library.

Plan 13-25 fixes the matching and marks every remaining guess with `LibrarySuggestion.weak`. This plan makes guesses visible and confirmable in the migration window, as the owner asked (decision 2026-11-12: "a visible 'check this library' note/strip line for weak suggestions, alternatives in the dropdown"):

- **Blocking strip line for a guess** (chosen over a non-blocking note; stated here, not decided silently): D-01 already blocks Run for a part "with no clear match"; a weak vote that nothing in the part's description confirms is not a clear match, so it gets a strip line until the owner picks a library. The suggestion still pre-fills the field, so confirming is one pick (plan 13-23 makes a list pick count). A confident suggestion gets no line, so the whole v1 fixture and the owner's normal parts are not slowed down.
- **Marks in the part list** for every library nobody confirmed ("suggested library", "library to check").
- **The reason as visible text** under the Library field, and **the alternatives in the dropdown**.

Purpose: a wrong guessed library can no longer reach Run unnoticed, and the right one is one pick away.
Output: `PartPlan.library_basis`, the guessed-library strip line, the window marks, note and dropdown, docs and tests.
</objective>
