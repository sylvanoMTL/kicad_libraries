## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user close requests -> running workers | Close, X, Escape and the main window's X arrive while kicad-cli, git or file reads may run |
| dialog lifetime -> QThread lifetime | the dialog owns its workers; destroying it under a running thread crashes the process |
