<objective>
Make the library tree treat `rel_path` as the identity of a library and make same-nickname libraries mutually exclusive.

Task 1 keys symbol and footprint items by `rel_path` (D-02), stops `populate()` from silently recomputing footprint selection (the HARD-07 blocker found in research: populate re-synced every source and threw restored footprint selection away), and scopes the footprint sync to the symbols of the same source. Task 2 adds the D-01 collision mark and mutual exclusion, including Select All.

Purpose: HARD-07 (selection survives a rescan) and HARD-08 (same-nickname libraries no longer overwrite each other) both depend on the widget not losing or mixing selection. Plan 02-06 relies on the no-resync populate when it re-applies selection after a rescan.
Output: updated `widgets/library_table.py` and its offscreen tests.
</objective>
