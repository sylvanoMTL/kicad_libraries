## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user/third-party lib table text -> merge | hand-edited tables may contain unknown fields, odd layout, bad escapes |
| repo library names and paths -> generated S-expression | file names become quoted table values |
| table write -> filesystem | KiCad, antivirus or a read-only flag may hold the file |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-07 | Tampering | generated table values | high | mitigate | every generated value through `sexpr.quote`; external entries never re-emitted; round-trip test with `"` and `\` in name and path |
| T-02-08 | Tampering | merge over unparseable or foreign table | high | mitigate | refuse on load Issue or root mismatch (D-09): no backup, no write; tests assert byte-identical file and no backup |
| T-02-09 | Denial of Service | partial table on lock, crash or I/O error | high | mitigate | fsutil atomic same-directory replace; per-file Issue; interrupted-replace test keeps original bytes |
