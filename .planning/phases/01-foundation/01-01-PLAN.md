Module constant `_TOKEN` compiled with re.S and named groups `open` for an opening paren, `close`, `str` matching a double-quoted string in which a backslash escapes any character, `atom` matching one or more characters that are not space, tab, CR, LF, a paren or a double quote, `ws` matching runs of space/tab/CR/LF only, and `bad` matching any single remaining character. Separators are ASCII space/tab/CR/LF only, never the regex whitespace class (Pitfall 9). `class SexprError(ValueError)` with `__init__(self, code: str, message: str, line: int, col: int)`, attributes `code`, `line`, `col`, and string form "<message> at line L, col C".
