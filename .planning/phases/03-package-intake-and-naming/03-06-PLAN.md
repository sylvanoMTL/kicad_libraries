## Executor environment (read before Task 1)

- Windows 11, Git Bash. Run commands from the checkout root with forward slashes. If `./env/Scripts/python.exe` is missing, create it with `py -3.14 -m venv env` and `./env/Scripts/python.exe -m pip install -r requirements-dev.txt`. Never stage `env/`.
- Python floor 3.10: detect junctions with the `st_file_attributes` reparse bit, not `Path.is_junction` (3.12+); walk with `os.scandir`, not `Path.walk` (3.12+).
- Creating a symlink on Windows needs Developer Mode or admin rights: the symlink test calls `pytest.skip` when `os.symlink` raises OSError or NotImplementedError. The junction test runs only on win32 and skips when `cmd /c mklink /J` fails.
- Test folders are built in `tmp_path`. To build the unzipped UL copy, the test reads each member of `UL_ZIP` with `zipfile` and writes it under `tmp_path` (trusted committed sample, never into the repo).
- Stage explicit paths only; never `git add -A`. Never stage `.planning/config.json`, `.planning/state.json`, `reports/` or `research_notes/`.

## Assumptions carried by this plan

- A9 (Claude's discretion, folder policy): folders use the zip caps; `MAX_MEMBERS` counts every file and folder entry walked, while `MAX_MEMBER_BYTES` / `MAX_TOTAL_BYTES` count only whitelisted files (non-whitelisted files are never read); depth limit 8; symlinks and junctions are skipped with an INFO Issue. A very large legitimate folder would be refused; the constants live in one place.
- Folder intake does not open `.zip` files it finds; they are listed as ignored (the user opens a zip directly).
