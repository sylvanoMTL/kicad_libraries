## Flagged Assumptions (edge probe)

The spec-less edge probe returned SCAN-02 as `unclassified / unresolved`. It stays unresolved and is surfaced here, not dropped:
- A symbol or footprint deleted since the last commit is not shown (there is no row for something that is gone).

- Two top-level symbols with the same name in one file: the first is compared and marked.
