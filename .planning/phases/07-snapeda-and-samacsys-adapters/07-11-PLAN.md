<objective>
Close UAT gap G-07-7. The preview table's columns can be resized by the user and stay readable when the Import part window is resized.

User decision (planning context, 2026-10-24, binding): the Item column is Interactive with a one-time initial width, stretchLastSection makes Detail fill the rest and elide, widths survive render() and rebuilds, and 05-UI-SPEC.md :315 and :511 are amended.

Root cause (.planning/debug/preview-table-columns-not-resizable.md): PreviewTree sets section 0 (Item) to Stretch and section 1 (Detail) to ResizeToContents, with stretchLastSection False and the horizontal scrollbar off, exactly as 05-UI-SPEC.md:315 prescribes. Neither section is Interactive, so the divider cannot be dragged. ResizeToContents pins Detail at its widest single-line text, about 734 px on Windows for the Phase 7 Field changes drop rows, which is wider than the 634 px viewport. Item then keeps a stale width or is squashed to about 80 px, and Detail is clipped. Rebuilds do not reset header widths (verified), so an Interactive width survives render().

Design choices (Claude's discretion, recorded here):
- One constant MIN_COLUMN_WIDTH = 120 px serves as the header's minimumSectionSize and as the clamp margin, so neither column drops below a readable width while the tree is at least 240 px wide (the right pane's minimum is 400 px).
- The initial width is applied in showEvent / resizeEvent once the tree is visible and its viewport is at least 2 x MIN_COLUMN_WIDTH wide. A probe on PySide6 6.12 offscreen showed the tree inside the QStackedWidget gets its real width in the first visible resize. Nothing in import_dialog.py changes.
- Path-rewrite Detail text is not capped. The decision lists the cap as optional. Detail now fits the viewport and wraps or elides with the full text in its tooltip, and cutting a path would hide what PREV-01 requires the preview to show.

Purpose: UAT test 7 passes. The owner can read and resize every preview column for SnapEDA and SamacSys parts, whose Field changes rows made the old layout unusable.

Output: the PreviewTree header contract, its widget and dialog tests, and the UI-SPEC amendment.
</objective>
